# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion about the
work. Harassment, discrimination and personal attacks are not tolerated.

To report unacceptable behaviour, use GitHub's
[report abuse](https://github.com/thiha-min-thant/canarybird/issues) or
[private vulnerability reporting](https://github.com/thiha-min-thant/canarybird/security/advisories/new)
form, or contact the maintainer listed in `charts/canarybird/Chart.yaml`.
Reports are handled confidentially.
